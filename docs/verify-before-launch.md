- [ ] **what-is-excess** — มีกรณีที่ต้องจ่ายค่าเสียหายส่วนแรกตามเงื่อนไขกรมธรรม์แม้ไม่ได้เลือกไว้ — ยืนยันกรณีตามแบบกรมธรรม์ปัจจุบัน
- [ ] **what-is-excess** — ค่าเสียหายส่วนแรกคิดต่อครั้ง
- [ ] **flood-cover** — น้ำท่วมรวมในชั้น 1 หลายแผน แต่ไม่ใช่ทุกแผน; ชั้นอื่นบางแผนมีหรือซื้อเพิ่มได้
- [ ] **flood-cover** — ข้อยกเว้นกรณีขับฝ่าน้ำท่วมโดยตั้งใจ
- [ ] **flood-cover** — คำแนะนำไม่ให้สตาร์ทเครื่องเมื่อน้ำท่วมถึงตัวรถ — ยืนยันว่าสอดคล้องกับคำแนะนำของบริษัทประกัน
- [ ] **ev-insurance** — มีแบบกรมธรรม์เฉพาะสำหรับรถยนต์ไฟฟ้า และหลักการคิดค่าเสื่อมแบตเตอรี่ตามอายุ
- [ ] **ev-insurance** — ความเสื่อมจากการใช้งานปกติไม่อยู่ในความคุ้มครอง
- [ ] **ev-insurance** — ความคุ้มครองเครื่องชาร์จ/สายชาร์จมีเฉพาะบางแผน

## FAQ (6)
_Source: `content/faq.ts`_

- [ ] **ราคาที่เห็นบนเว็บเป็นราคาสุดท้ายไหม** — ขั้นตอนยืนยันราคา/ตรวจสภาพรถก่อนออกกรมธรรม์ — ยืนยันตามกระบวนการจริงของแต่ละบริษัท
- [ ] **ซื้อประกันผ่านเว็บได้อย่างไร** — ช่องทางชำระเงินและแผนที่ซื้อออนไลน์ได้ครบขั้นตอน — ยืนยันก่อนเปิดใช้งาน
- [ ] **ผ่อนชำระเบี้ยประกันได้ไหม** — เงื่อนไขการผ่อนชำระ (จำนวนงวด ดอกเบี้ย ช่องทาง) — ยืนยันกับพาร์ทเนอร์ชำระเงิน/บริษัทประกัน
- [ ] **พ.ร.บ. กับประกันรถภาคสมัครใจต่างกันอย่างไร** — รถทุกคันต้องมี พ.ร.บ. ตามกฎหมาย
- [ ] **พ.ร.บ. กับประกันรถภาคสมัครใจต่างกันอย่างไร** — พ.ร.บ. คุ้มครองเฉพาะความเสียหายต่อชีวิตร่างกาย ไม่คุ้มครองตัวรถ/ทรัพย์สิน
- [ ] **รถไฟฟ้า (EV) ทำประกันต่างจากรถทั่วไปไหม** — หลักการคิดค่าเสื่อมแบตเตอรี่ในกรมธรรม์รถยนต์ไฟฟ้า

## Claims guidance (32)
_Source: `content/claims.ts`_

- [ ] **ชนกับรถคันอื่น** — การที่บริษัทประกันส่งเจ้าหน้าที่ไปที่จุดเกิดเหตุ ขึ้นกับแต่ละบริษัทและพื้นที่
- [ ] **ชนกับรถคันอื่น** — กรณีใดที่บริษัทประกันต้องการใบแจ้งความหรือบันทึกประจำวัน
- [ ] **ชนกับรถคันอื่น** — เบอร์ฉุกเฉินที่ระบุใน emergencyNote (1669 เจ็บป่วยฉุกเฉิน, 191 ตำรวจ) ยังถูกต้อง
- [ ] **ชนกับรถคันอื่น** — ผลของการตกลงกับคู่กรณีเองต่อสิทธิการเคลม — ยืนยันตามเงื่อนไขกรมธรรม์
- [ ] **ชนกับรถคันอื่น** — รายการเอกสารที่บริษัทประกันโดยทั่วไปขอสำหรับการเคลมแบบมีคู่กรณี
- [ ] **ชนแบบไม่มีคู่กรณี** — โดยทั่วไปเฉพาะชั้น 1 ที่คุ้มครองตัวรถกรณีชนแบบไม่มีคู่กรณี
- [ ] **ชนแบบไม่มีคู่กรณี** — ค่าเสียหายส่วนแรกกรณีชนแบบไม่มีคู่กรณี — ยืนยันตามเงื่อนไขกรมธรรม์ ห้ามระบุจำนวนเงินในข้อความ
- [ ] **ชนแบบไม่มีคู่กรณี** — ระยะเวลาที่ควรแจ้งเคลมหลังเกิดเหตุ ตามเงื่อนไขกรมธรรม์
- [ ] **ชนแบบไม่มีคู่กรณี** — ผลของการซ่อมก่อนแจ้งบริษัทประกันต่อสิทธิการเคลม
- [ ] **รถโดนน้ำท่วม** — ความคุ้มครองน้ำท่วมแตกต่างตามแผน และข้อยกเว้นกรณีขับฝ่าน้ำท่วมโดยตั้งใจ — ยืนยันตามแบบกรมธรรม์
- [ ] **รถโดนน้ำท่วม** — คำแนะนำเรื่องการเคลื่อนย้ายรถหลังน้ำท่วมและบริการรถยกของบริษัทประกันโดยทั่วไป
- [ ] **รถโดนน้ำท่วม** — การที่ความเสียหายเพิ่มเติมจากการสตาร์ทรถหลังน้ำท่วมอาจส่งผลต่อการเคลม
- [ ] **รถหาย** — ความคุ้มครองรถหายขึ้นกับประเภทประกัน (โดยทั่วไปชั้น 1, 2+, 2) — ยืนยันตามแบบกรมธรรม์
- [ ] **รถหาย** — การเคลมรถหายต้องใช้หลักฐานการแจ้งความ และระยะเวลาที่ควรแจ้ง
- [ ] **รถหาย** — รายการเอกสารสำหรับเคลมรถหาย เช่น เล่มทะเบียน กุญแจ และขั้นตอนระยะเวลารอก่อนพิจารณา
- [ ] **ไฟไหม้รถ** — ความคุ้มครองไฟไหม้ขึ้นกับประเภทประกัน (โดยทั่วไปชั้น 1, 2+, 2, 3+) — ยืนยันตามแบบกรมธรรม์
- [ ] **ไฟไหม้รถ** — กรณีไฟไหม้ต้องใช้หลักฐานการแจ้งความหรือเอกสารจากหน่วยงานใด
- [ ] **ไฟไหม้รถ** — เบอร์หน่วยดับเพลิงที่ควรระบุในหน้า (ข้อความขั้นตอนยังไม่ได้ใส่ตัวเลข)
- [ ] **กระจกแตกหรือร้าว** — ความคุ้มครองกระจกแยกจากการชนหรือไม่ และมีผลต่อค่าเสียหายส่วนแรกหรือประวัติเคลมอย่างไร — ยืนยันตามแบบกรมธรรม์
- [ ] **กระจกแตกหรือร้าว** — การเลือกร้านซ่อมกระจกและการเปลี่ยนกระจกเทียบเท่าหรือของแท้ ตามเงื่อนไขกรมธรรม์
- [ ] **กระจกแตกหรือร้าว** — ค่าตั้งค่ากล้องหรือเซนเซอร์หลังเปลี่ยนกระจกอยู่ในความคุ้มครองหรือไม่
- [ ] **แบตเตอรี่รถไฟฟ้าเสียหาย** — เงื่อนไขความคุ้มครองแบตเตอรี่รถ EV การซ่อมหรือเปลี่ยน และการคำนวณค่าเสื่อม — ยืนยันตามแบบกรมธรรม์
- [ ] **แบตเตอรี่รถไฟฟ้าเสียหาย** — คำแนะนำด้านความปลอดภัยหลังแบตเตอรี่รถไฟฟ้าเสียหาย — ให้ผู้เชี่ยวชาญหรือคู่มือผู้ผลิตยืนยัน
- [ ] **แบตเตอรี่รถไฟฟ้าเสียหาย** — คำแนะนำเรื่องรถยกแบบสไลด์สำหรับรถไฟฟ้า
- [ ] **แบตเตอรี่รถไฟฟ้าเสียหาย** — การเคลมแบตเตอรี่อาจต้องตรวจที่ศูนย์บริการที่ผู้ผลิตรับรอง — ยืนยันตามเงื่อนไขกรมธรรม์
- [ ] **ควรแจ้งเคลมกับใคร** — ขอบเขตการช่วยเหลือเรื่องเคลมของ Unlimit ยังไม่ได้กำหนด — ต้องยืนยันก่อนเพิ่มข้อความเกี่ยวกับบทบาทของเรา
- [ ] **Unlimit ช่วยเรื่องเคลมได้แค่ไหน** — ขอบเขตการช่วยเหลือเรื่องเคลมของ Unlimit (แจ้งแทน ประสานงาน ติดตามสถานะ หรือไม่มี) ยังไม่ได้กำหนด — ห้ามสัญญาว่าจะดำเนินการ เร่ง หรือรับประกันผลการเคลม
- [ ] **Unlimit ช่วยเรื่องเคลมได้แค่ไหน** — ช่องทางติดต่อของ Unlimit สำหรับลูกค้าหลังการขาย
- [ ] **ต้องแจ้งเคลมภายในเวลาเท่าไร** — ระยะเวลาการแจ้งเคลมที่กำหนดในแบบกรมธรรม์ และผลของการแจ้งล่าช้า
- [ ] **ต้องแจ้งความทุกครั้งไหม** — กรณีที่ต้องมีใบแจ้งความหรือบันทึกประจำวันประกอบการเคลม ตามแนวปฏิบัติของบริษัทประกันและกฎหมาย
- [ ] **เคลมแล้วจะมีผลกับเบี้ยปีหน้าไหม** — ผลของประวัติเคลมต่อส่วนลดประวัติดีและเบี้ยต่ออายุ ตามหลักเกณฑ์ที่ใช้อยู่
- [ ] **ถ้าหาเบอร์แจ้งเคลมไม่เจอ ทำอย่างไร** — My Garage แสดงเบอร์แจ้งเคลมของบริษัทประกันจากข้อมูลกรมธรรม์ที่ยืนยันแล้ว
