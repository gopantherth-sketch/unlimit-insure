## Post 3 · Wed 12-02 · type1-vs-2plus

```
ประกันชั้น 1 กับ 2+ ต่างกันตรงไหน

ทั้งสองชั้นดูแลรถคุณเมื่อชนกับรถคันอื่นที่ระบุคู่กรณีได้ และโดยทั่วไปรวมไฟไหม้กับรถหาย

จุดที่ต่างกันชัดคือการชนแบบไม่มีคู่กรณี

• ชั้น 2+ มักไม่ดูแลกรณีนี้
• น้ำท่วม ขึ้นอยู่กับแต่ละแผน ควรเช็กทุกครั้ง

ไม่มีคำตอบเดียวที่ถูกสำหรับทุกคน ลองดูตารางเทียบในบทความ 👉 https://unlimitinsure.com/lab/type1-vs-2plus
```

## Post 4 · Fri 12-04 · what-is-excess

```
ค่าเสียหายส่วนแรก (Excess) คืออะไร

สั้น ๆ คือเงินที่คุณจ่ายเองก่อนในแต่ละครั้งที่เคลม ส่วนที่เกินจากนั้นบริษัทประกันดูแลตามเงื่อนไข

• บางแผนให้เลือกรับค่าเสียหายส่วนแรก เพื่อแลกกับเบี้ยที่ถูกลง
• บางกรณีอาจมีค่าเสียหายส่วนแรกตามเงื่อนไขกรมธรรม์ แม้ไม่ได้เลือกไว้
• ถ้าค่าซ่อมครั้งนั้นน้อยกว่าค่าเสียหายส่วนแรก คุณจ่ายเองทั้งหมด

ลองคิดกับตัวอย่างในบทความว่าแบบไหนเหมาะกับการใช้รถของคุณ 👉 https://unlimitinsure.com/lab/what-is-excess

เป็นไปตามเงื่อนไขของแต่ละกรมธรรม์
```

## Post 5 · Wed 12-09 · dealer-vs-garage

```
ซ่อมศูนย์ กับ ซ่อมอู่ เลือกแบบไหนดี

ทั้งสองแบบบริษัทประกันดูแลค่าซ่อมตามเงื่อนไขกรมธรรม์เหมือนกัน ที่ต่างคือสถานที่ซ่อมและเบี้ย

เรื่องที่คนส่วนใหญ่ใช้ตัดสินใจ
• เบี้ย: ซ่อมศูนย์มักสูงกว่าซ่อมอู่
• อายุรถ: หลายบริษัทรับซ่อมศูนย์เฉพาะรถที่อายุไม่เกินที่กำหนด
• ความสะดวก: ศูนย์หรืออู่ในเครืออยู่ใกล้บ้านหรือที่ทำงานไหม
• ระยะเวลาซ่อม: ขึ้นกับคิวงานและอะไหล่ของแต่ละที่

อ่านวิธีคิดเทียบ 👉 https://unlimitinsure.com/lab/dealer-vs-garage
```

## Post 6 · Fri 12-11 · flood-cover

```
รถน้ำท่วม ประกันคุ้มครองไหม

ไม่ใช่ทุกแผนที่รวมความคุ้มครองน้ำท่วม หลายแผนชั้น 1 รวมไว้แล้ว แต่บางแผนไม่มี วิธีง่าย ๆ คือเช็กในรายละเอียดแผนว่ามีความคุ้มครองน้ำท่วมหรือภัยธรรมชาติหรือไม่

ถ้าน้ำท่วมถึงตัวรถ
• ไม่ควรสตาร์ทเครื่องทันที
• ถ่ายรูปสภาพรถและระดับน้ำไว้
• ติดต่อบริษัทประกันตามช่องทางในกรมธรรม์

บางกรมธรรม์มีข้อยกเว้น เช่น ขับฝ่าน้ำท่วมโดยตั้งใจ อ่านต่อ 👉 https://unlimitinsure.com/lab/flood-cover

การพิจารณาความคุ้มครองเป็นไปตามเงื่อนไขของบริษัทประกัน
```

```
• ที่รับซ่อมรถ EV ในพื้นที่ของคุณ และบริการลากรถ

รายการเช็กก่อนเลือกแผน 👉 https://unlimitinsure.com/lab/ev-insurance
```

## Post 8 · Fri 12-18 · ev-claims

```
รถ EV เคลมประกันต่างจากรถทั่วไปไหม

ขั้นตอนหลักเหมือนเดิม: แจ้งบริษัทประกัน ทำตามที่เจ้าหน้าที่แนะนำ แล้วนำรถเข้าซ่อมตามเงื่อนไข

ถ้าเห็นควันหรือได้กลิ่นไหม้ ให้ออกห่างจากรถแล้วโทรแจ้งเหตุ และอย่าแตะชิ้นส่วนที่เสียหาย

อ่านต่อ 👉 https://unlimitinsure.com/lab/ev-claims
```
